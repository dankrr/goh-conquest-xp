# v0.1.0

Initial release for Gates of Hell 1.0.6.7-aaa36ed4d on Linux / Proton.

- Enables the game's normal single-player Dynamic Conquest XP eligibility with scene-affecting Workshop mods.
- Preserves the original Steam and XP calculation paths.
- Installs without overwriting existing DLLs and can be removed with the included script.
- One live four-mod battle displayed 179 XP and updated the local Steam stats cache. Server synchronization and persistence after restart are not yet verified.
- Experimental achievement support is off by default and has not been verified. Use in solo Conquest only.
